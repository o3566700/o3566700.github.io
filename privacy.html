Hermes – Privacy Policy

Last updated: 2026-10-18

Hermes is a personal assistant used only by its owner, Myjian (o3566700@gmail.com). It is not offered to the public.

Data accessed

  • Gmail – read-only (gmail.readonly): message metadata such as subjects, used to produce a daily summary.
  • Google Contacts – read-only (contacts.readonly).

Hermes does not send, modify or delete email or contacts.

How data is processed

  • Data is processed locally on the owner's own computer. OAuth tokens are stored only on that computer.
  • To create summaries, limited text (for example email subjects) may be sent to AI model providers (such as Google Gemini, DeepSeek or Anthropic Claude) under their API terms.
  • Data is not sold, not shared with third parties for advertising, and not used for any purpose other than the owner's own assistant.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
